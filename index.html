GRAPE: Graph-Augmented Prototype Explanations for Interactive Medical Image Diagnosis

Rasul Khanbayov,  Erchin Serpedin,  Hasan Kurban
Accepted to NeurIPS 2026 🎉

Prototype-based medical image classifiers treat clinical findings as independent, silently amplify unsafe physician feedback, and require full retraining to add a new finding. GRAPE resolves all three limitations in one architecture: a graph attention task head that models anatomical concept co-occurrence, a concept-mismatch safety check that catches erroneous clinician corrections before they are applied, and open-vocabulary prototype anchoring that adds a new finding from a single labeled image, with only +1ms added latency at interactive batch size.

Pointing Game on TBX11K chest X-rays (Active TB concept). Each marker shows the max-activation point of a method; GRAPE (orange circle) consistently localizes the lesion inside the ground-truth bounding box (cyan) where CSR, CBM, and PIP-Net scatter to irrelevant regions.

Three Modules, One Architecture

Module A — Graph Attention Task Head

Builds a data-driven concept co-occurrence graph from training labels and refines prototype similarity scores via graph attention before classification, boosting macro-F1 by +13.8 pp over the prototype baseline on TBX11K.

Module B — Concept-Mismatch Safety Check

The first such mechanism in prototype-based medical classifiers: warns when the model's dominant finding inside a doctor-drawn region conflicts with the claimed label, catching 85% of erroneous annotations versus 51% for MC-Dropout, at no extra inference cost.

Module C — Open-Vocabulary Prototype Anchoring

Aligns visual prototypes to frozen BioViL-T text embeddings, letting a new clinical finding be added from a single labeled image without modifying any other component of the model.
